Defined in: [SequelizeGuard.ts:50](https://github.com/lotivo/sequelize-guard/blob/ecc63e3560c6e84ae64359413e59fb8116935cc8/packages/sequelize-guard/src/SequelizeGuard.ts#L50)

SequelizeGuard - Authorization library for Sequelize

## Example

```typescript
const sequelize = new Sequelize(...);
const guard = new SequelizeGuard(sequelize, options);

// Assign roles
await user.assignRole('admin');

// Create permissions
await guard.allow('admin', ['view', 'edit'], 'blog');

// Check permissions
const canEdit = await user.can('edit blog');
```

### ready

> `readonly` **ready**: `Promise`\<`void`\>

Defined in: [SequelizeGuard.ts:71](https://github.com/lotivo/sequelize-guard/blob/ecc63e3560c6e84ae64359413e59fb8116935cc8/packages/sequelize-guard/src/SequelizeGuard.ts#L71)

Automatic startup completion, including model sync and cache initialization.
With sync: false, resolves without database work; await sync() separately
or prepare the tables with migrations before using the guard.

#### Example

```typescript
const guard = new SequelizeGuard(sequelize, { sync: true });
await guard.ready;
// Now safe to use guard
```

### sync()

> **sync**(`options`): `Promise`\<`SequelizeGuard`\>

Defined in: [SequelizeGuard.ts:108](https://github.com/lotivo/sequelize-guard/blob/ecc63e3560c6e84ae64359413e59fb8116935cc8/packages/sequelize-guard/src/SequelizeGuard.ts#L108)

Synchronize guard models, then reload their cached roles and permissions.
Calls are serialized, including automatic startup. Errors reject the caller.
Includes a supplied UserModel; unrelated Sequelize models are not synced.
schema must match every model's bound schema; per-call searchPath is rejected.

#### Parameters

##### options

`SyncOptions` = `{}`

Sequelize sync options. force and alter may destroy data.

#### Returns

`Promise`\<`SequelizeGuard`\>

This guard after synchronization and cache initialization complete.
