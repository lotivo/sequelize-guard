## Prerequisites

Before installing Sequelize Guard, make sure you have:

- Node.js 22.17.1 or later. CI tests Node.js 22 and 24.
- Sequelize `^6.37.8`
- A database with its Sequelize driver. The test suite covers SQLite, PostgreSQL 17 and MySQL 8.4.

## Package Installation

Install Sequelize Guard using your preferred package manager:

```bash tab="npm"
npm install sequelize-guard
```

```bash tab="pnpm"
pnpm add sequelize-guard
```

```bash tab="yarn"
yarn add sequelize-guard
```

```bash tab="bun"
bun add sequelize-guard
```


## Peer Dependencies

Sequelize Guard requires Sequelize as a peer dependency. If you haven't installed it yet:

```bash npm2yarn
npm install "sequelize@^6.37.8"
```

You'll also need to install the database driver for your database:

#### PostgreSQL

```bash tab="npm"
npm install pg pg-hstore
```




## Verify Installation

With the SQLite driver installed, save this example as `test-guard.mjs`. It initializes Guard in a disposable in-memory database.

```javascript filename="test-guard.mjs"
import { SequelizeGuard } from 'sequelize-guard';
import { Sequelize } from 'sequelize';

const sequelize = new Sequelize({
  dialect: 'sqlite',
  storage: ':memory:',
  logging: false,
});
try {
  const guard = new SequelizeGuard(sequelize);
  await guard.ready;
  console.log('Sequelize Guard installed successfully!');
} finally {
  await sequelize.close();
}
```

Run the test:

```bash
node test-guard.mjs
```

If you see the success message, you're ready to start using Sequelize Guard!
