## Features

- **🔐 Role-Based Access Control** - Define roles and permissions for your application
- **🎯 Resource-Level Permissions** - Control access to specific resources
- **👥 User Management** - Built-in user-role associations
- **⚡ Current Authorization** - Check roles and permissions against the writer database
- **🔄 Migration Support** - Easy database schema setup
- **📦 TypeScript Support** - Full type definitions included
- **🧪 Well Tested** - Comprehensive test coverage
- **🎨 Flexible API** - Simple and intuitive API design

## Quick Example

This example uses SQLite in memory. Install Sequelize and `sqlite3` using the [installation guide](/docs/guide/installation).

```typescript
import { SequelizeGuard } from 'sequelize-guard';
import { Sequelize } from 'sequelize';

const sequelize = new Sequelize({
  dialect: 'sqlite',
  storage: ':memory:',
  logging: false,
});
try {
  const guard = new SequelizeGuard(sequelize);
  await guard.ready;

  const user = await guard.makeUser();
  await guard.allow('admin', 'create', 'users');
  await guard.assignRole(user, 'admin');
  console.log(await user.can('create users')); // true
} finally {
  await sequelize.close();
}
```

## Why Sequelize Guard?

Sequelize Guard adds role-based access control to your Node.js applications:

- **Easy Integration** - Works seamlessly with existing Sequelize projects
- **Production Setup** - Prepare Guard tables with [explicit migrations](/docs/guide/db-migrations)
