Candidate 6.1.0 documentation. Start with [installation](/docs/guide/installation), [initialization](/docs/guide/getting-started), [security](/docs/guide/authorization), [upgrade](/docs/migration/upgrade-to-v6) and [API reference](/docs/api).

The 6.1.0 candidate targets Node 22 (minimum 22.17.1) and 24, Sequelize `^6.37.8`, SQLite, PostgreSQL 17 and MySQL 8.4. Install the dialect driver your application needs. Sequelize 7 and other dialects are outside this tested contract. Native ESM and CommonJS are shipped, with strict TypeScript 5.9 consumer coverage for NodeNext import/require and Bundler resolution.

6.1.0 deliberately keeps the package major aligned with Sequelize 6. It changes policy, schema and lifecycle contracts: its minor version is **not a drop-in compatibility promise**. Published 6.0.2 is immutable; candidate fixes are not a published security release. See [upgrade instructions](/docs/migration/upgrade-to-v6).
