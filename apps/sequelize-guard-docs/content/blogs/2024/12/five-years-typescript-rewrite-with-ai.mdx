This historical post records the move from the original JavaScript project to TypeScript. It is not a release announcement for the current 6.1.0 candidate. Earlier API and compatibility examples have been retired because they did not match the public package.

For current behavior, use the [initialization guide](/docs/guide/getting-started), [shared executable examples](/docs/examples), [security contract](/docs/guide/authorization) and [offline upgrade guide](/docs/migration/upgrade-to-v6). The maintained package targets Sequelize 6, uses writer-backed authorization and leaves authentication and durable auditing to applications.
